## 사이트

- 회귀분석: https://hwangjunkr.github.io/regression/
- 인공신경망: https://hwangjunkr.github.io/regression/neural-network.html

## 파일

| 파일 | 내용 |
|---|---|
| index.html | 회귀분석 페이지 |
| neural-network.html | 인공신경망 결과 페이지 |
| linear_regression.py | 선형회귀 파이썬 버전 |
| cover.png | 노션 표지 이미지 |

파이썬 버전은 `pip install numpy matplotlib` 후 `python linear_regression.py`로 실행합니다. CSV를 쓰려면 파일 경로를 뒤에 붙입니다.
